# Support

## I want to know whether my app can upgrade

Run the checker against your project:

```bash
npx solid-ground check package.json
```

or use the [“Check my app” page](https://joeyhammoth.github.io/SolidGround/check/)
once the site is live. Both read the published dataset and never upload your
files.

## A package's status looks wrong

Use the [correction form](https://github.com/JoeyHammoth/SolidGround/issues/new?template=correct-status.yml)
with a link to evidence: a release, a CI run, a pull request or a tarball.
Maintainers of the package are prioritised.

## I want a package added

Use the [add-package form](https://github.com/JoeyHammoth/SolidGround/issues/new?template=add-package.yml).
Discovery is not exhaustive; requests are welcome.

## I have a question or an idea

Open a [discussion](https://github.com/JoeyHammoth/SolidGround/discussions).
Methodology proposals belong there too.

## I found a security issue

Do not open a public issue. Follow [`SECURITY.md`](SECURITY.md).

## I want to contribute code

Start with [`CONTRIBUTING.md`](CONTRIBUTING.md), then look at issues labelled
[`good first issue`](https://github.com/JoeyHammoth/SolidGround/labels/good%20first%20issue).
