## Open roles

The project is recruiting a **second maintainer** with admin access and a
**second Code of Conduct contact** (see
[issue #10](https://github.com/JoeyHammoth/SolidGround/issues/10)). Until both
exist, the bus factor is one and this is stated openly rather than hidden.

To be considered, contribute steadily over a few weeks — data corrections with
evidence, review comments, docs or pipeline work all count — and say you are
interested in a Discussion.

## Responsibilities

- Triage issues and PRs, ask for evidence, and label accurately.
- Review changes to `rules/`, `packages/engine/` and `.github/` with extra care.
- Keep the default branch green and the README accurate.
- Publish releases and keep the changelog honest.
- Handle corrections from package maintainers with priority and neutrality.
- Never let a sponsor or employer influence a status.
- Disclose conflicts of interest on packages you maintain.

## Response expectations

| Channel | Target |
|---|---|
| Security report | Acknowledge within 3 business days; triage within 7 |
| Data correction | First response within 5 business days; correction target 7 |
| Issue or PR | First response within 5 business days |
| Code of Conduct report | Acknowledge within 3 days |

These are targets, not guarantees. If a maintainer is unavailable, a polite ping
is welcome; the runbook in [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md) and the
pipeline issues describe how automation keeps running.

## Contacts

- **Security:** private vulnerability reporting on the Security tab. See [`SECURITY.md`](SECURITY.md).
- **Conduct:** privately contact a maintainer listed above.
- **Everything else:** [Discussions](https://github.com/JoeyHammoth/SolidGround/discussions) or [Issues](https://github.com/JoeyHammoth/SolidGround/issues).
