# M0 spike results (2026-11-25)

The design document marked several assumptions with ⚠. This note records what was
checked, how, and what the implementation now assumes. Anything not verified is
called out as such rather than presented as fact.

## Verified live

| Question | Result | Method |
|---|---|---|
| Is Solid 2 stable published? | Yes. `solid-js` dist-tags on 2026-11-25: `latest: 2.0.3`, `next: 2.0.0-rc.23`, `v1-latest: 1.9.20`. | `GET https://registry.npmjs.org/solid-js` |
| Is `solid-ground` available on npm? | **No.** The package name already resolves (HTTP 200), so the unscoped CLI name is taken. `@solid-ground/cli` returned 404 and is available. | registry lookup |
| Does the abbreviated npm metadata include `peerDependenciesMeta`? | **No.** With `Accept: application/vnd.npm.install-v1+json`, `@kobalte/core@0.13.14` omits `peerDependenciesMeta` while carrying `peerDependencies`. | conditional request with install Accept header |
| Does a bulk npm downloads endpoint exist? | **No** at the documented path. `POST /downloads/point/last-week` with `{packages:[...]}` returns 404. One request per package it is. | live request |
| npm search pagination | `size` is honoured; `total` is available for paging (495 results for `keywords:solid-js` at the time of check). The 250-per-page ceiling was **not** probed. | `GET /-/v1/search?text=keywords:solid-js&size=5` |
| GitHub GraphQL batching cost | A `rateLimit` query costs 1 point; authenticated limit was 5,000 points/hour for the personal token used during setup. | `query { rateLimit { cost remaining limit } }` |
| Astro + Pagefind | Supported. Pagefind runs after `astro build` and writes a chunked static index; the `astro-pagefind` integration is the recommended path. | Pagefind and Astro docs |
| Harden-Runner egress block | `egress-policy: block` with `allowed-endpoints` is available on the free Community tier for **public repositories on GitHub-hosted runners**. Start in `audit` mode, then switch. | StepSecurity docs |

## Decisions that follow

1. **Use the full packument**, not the abbreviated install format, until a
   registry variant is proven to carry `peerDependenciesMeta`. Optional peers
   change how a missing `solid-js` peer is read.
2. **One downloads request per package**, concurrency ≤ 4, and a missing value
   is stored as `null`, never zero.
3. **Name:** the CLI publishes as `@solid-ground/cli`; the repository keeps the
   Solid Ground name. The unscoped `solid-ground` npm name is unavailable, so
   installation docs must not promise `npx solid-ground` until a scope or
   alternative is confirmed.
4. **Discovery** pages with `size` and `from`; do not assume 250 per page.
5. **GitHub** batching of ~25 repositories stays well inside the documented
   1,000 GraphQL points per repository per hour for `GITHUB_TOKEN`; read
   `rateLimit` on every response and stop below 100 remaining.
6. **Pagefind** is deferred until the site has enough content to justify the
   extra build step; the MVP ships a client-side filter over `index.json`.
7. **Harden-Runner** will start in `audit` mode in the first verify workflow,
   then move to `block` with the npm and GitHub endpoints allowlisted.

## Still unverified (tracked as issues)

- The 60-day scheduled-workflow disable rule and whether a bot heartbeat commit
  resets it. Mitigation: watchdog plus an external dead-man's switch; test by
  observing a quiet period.
- The npm search page ceiling (250) and whether deps.dev / ecosyste.ms give a
  reliable `solid-js` dependents count.
- Whether `@solid-ground/cli` will be the final published name, and whether a
  custom domain is wanted.
- Free-tier billing details for GitHub-hosted runners; assume free for public
  repositories but confirm before scaling the smoke matrix.
